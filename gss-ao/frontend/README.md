# Frontend GSS-AO (scaffold)

Scaffold Next.js (App Router) **non fonctionnel** en itération 1 — uniquement la
structure de dossiers et une page d'accueil statique.

```bash
npm install
npm run dev   # http://localhost:3000
```

> L'itération 1 se concentre sur le backend (parseurs RC/CCTP + ingestion RAG).
> Le workflow guidé (brief §8.3) et l'éditeur WYSIWYG (TipTap/Lexical) viendront
> ensuite. `tsconfig.json` / config Tailwind seront ajoutés au branchement réel.
